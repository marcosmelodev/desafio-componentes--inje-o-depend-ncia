# Desafio: Componentes e Injeção de Dependência

Este repositório contém a minha resolução para o desafio proposto no módulo de **Componentes e Injeção de Dependência** do curso de Java Spring da **DevSuperior**, ministrado pelo **Professor Nélio Alves**.

### 🎯 Objetivo do projeto
O objetivo principal foi aplicar os conceitos de inversão de controle e injeção de dependência em um sistema de pedidos, calculando o valor total com base em regras de frete e desconto utilizando componentes desacoplados.
